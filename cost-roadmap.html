成本与实施路线图

一句话：按"一步到位"版估算，搭建费约 $15–40 万，每月运营全口径约 $3,000–20,000（其中 AWS 部分约 $900–4,000），周期约 5–7 个月。同样职能的传统团队（6–8 人）在美国一年约 $60–100 万。所有数字都是 📌 估算，前期准备完成后会出正式报价。

#搭建费：几种路线对比

方案 搭建费 首年总成本（含监督人员） 每月运营
精益版（低代码，Owner 加 1 名自由职业工程师） $1–3 万 $6–15 万 $1,000–8,000
标准版（混合路线，外包工作室或 2–3 人团队） $5–15 万 $15–40 万 $1,000–8,000
企业版（Agentforce 或完全自研，合规要求高） $20–50 万以上 $50 万以上 —
订阅"AI 员工" + 自建骨架 $1–4 万 — $1,000–7,000
一步到位版（推荐的架构） $15–40 万 — $3,000–20,000

搭建费区间很宽，主要取决于三件事：业务有多标准化（决定生产AI的复杂度）、要接多少外部系统、合规要求多高。这些都要在 前期准备 里回答。

#AWS 部分每月多少钱

规模假设：每月 200 条线索、20 个活跃客户、约 5,000 次人物会话、约 5 万次工具调用、约 1.5 亿 token。

项 每月 依据
账号与安全基线（8 个账号） $80–200 Config、GuardDuty、Security Hub、KMS 等（📚）
网络 $350–450 私有接口端点约 $300 ✅ + NAT + DNS 防火墙
AgentCore Runtime $30–100 按 vCPU 和内存小时计费；等待 I/O 时不收 CPU 费 ✅
Gateway + Policy 低于 $5 每千次调用 $0.005 ✅
Memory $5–20 ✅
Evaluations $30–150 ✅
模型 token $300–2,500 最大的变量。复核会让用量多出 30–50%；提示词缓存能省下不少
Guardrails $50–400 按文本单位计费，只在边界上检测才能控制成本 ✅
知识库 $25–60 ✅
骨架与存储 $20–60 Step Functions、DynamoDB、S3（📚）
入口 $20–40 WAF、CloudFront、SES、API Gateway（📚）
AWS 合计 约 $900–4,000
AWS Quick（可选） 约 $290 1 名用户 Enterprise 档

#容易漏掉的成本

  • 人工监督：前 6 个月建议 0.5–1 人的"AI 运营"协助 Owner。
  • 维护费：每年约为搭建费的 20–40%（模型升级、平台变化、规则调整）。
  • 保险：科技 E&O + 网络安全险约 $5k–8k/年（11-13 按创业公司中位数上调），而且要确认 AI 相关的承保条款。
  • 得州合规一次性：律师审查 $5k–15k；会计设置销售税 $1k–3k；如果做电话外联，登记 $200 + $10,000 保证金。
  • 销售税：买软件和云服务多出约 5%–6.6%。
  • 试错成本：域名被拉黑、报错价格等。

#实施路线图

阶段 时长 内容 完成标准
前期准备 3–6 周 贵司提供业务信息、资料和决策；我们出定稿设计和报价（见 前期准备） "可以开工"清单全部打勾
0 地基 3–4 周 8 个账号和组织级护栏；统一登录；日志和安全基线；治理仓库（宪章、阈值、人物卡）；得州法律事务 规则测试全部通过；审计账本"能写不能删"
1 控制面和知识 4–6 周 网关 + 策略 + 拦截器；执行器和审批服务；Owner 控制台；知识库和入库流水线；隔离读信员、复核官、幕僚长以 A0 上线 跨客户泄漏为 0；第一轮红队通过
2 获客到报价 4–6 周 获客AI、前台AI、销售AI 从 A0 升到 A1；状态机前半段 Owner 每天审批用时少于 1 小时
3 合同、收款、交付 6–8 周 合同AI、财务AI、项目/生产/质检AI；接入电子签和 Stripe 完成第一笔端到端成交
4 客户成功和放权 持续 客户成功AI；按数据逐个动作晋升到 A2、A3；成本优化 自动化率达到目标

合计约 5–7 个月（不含前期准备）。

#可以并行做的概念验证

  • Paperclip：2–4 周，先放内部岗位，同时按加固清单处理安全问题。
  • AWS Quick：30 天试用，先做后台流程和 Owner 看板。
  • 评估集：前期准备阶段就可以开始收集真实对话，越早越好。
