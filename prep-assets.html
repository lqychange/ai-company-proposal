② 资料与账号清单

用法：每一项前面的方框可以直接勾选，进度保存在您这台电脑的浏览器里（换电脑或清缓存会丢失）。

优先级：P0 定稿设计前需要；P1 搭建第 0–1 阶段需要；P2 上线前需要即可。

#1. 业务知识资料（进知识库）

这些资料决定 AI 说的话对不对。有多少给多少，草稿、旧版、零散的笔记都可以，我们会帮忙整理。

  • P0 服务目录与价格表：每项服务的名称、包含什么、不包含什么、价格、交付周期、可选附加项。
  • P0 定价与折扣规则：什么情况能打折、最多打几折、年付或批量怎么算。
  • P0 交付流程（SOP）：从签约到验收的每一步，谁做、用什么工具、产出什么。可以是文字、流程图或录屏讲解。
  • P0 验收标准：交付物怎样算合格，最好有一份检查清单。
  • P1 合同模板：主服务协议、工作说明书（SOW）、订单表。
  • P1 条款谈判手册：哪些条款可以让步、让到什么程度、哪些绝对不能改（如责任上限、知识产权归属）。
  • P1 常见问题（FAQ）与异议处理：客户最常问什么、最常拒绝的理由、怎么回应。
  • P1 品牌语气指南：用词偏好、禁用词、参考文案，以及 2–3 封您认为写得好的邮件。
  • P1 客户案例：3–5 个，须取得客户书面授权才能对外使用。
  • P1 退款、售后与服务承诺（SLA）政策。
  • P2 竞品对比：主要竞争对手、我们的差异（只用可以证实的说法）。
  • P2 邮件模板：外联、跟进、催款、续约提醒等现有模板。
  • P2 已批准的宣传用语：对外可以说的能力和效果。这份清单会成为"已批准宣传用语库"，是防误导性宣传的主要手段。

#2. 测试样例（做评估集）

每个 AI 岗位上线前都要先"考试"。考题来自贵司的真实业务，越真实越好。请去掉或替换客户的姓名、邮箱和电话。

  • P0 10–20 段客户对话（邮件往来或聊天记录），涵盖询价、谈判、投诉、续约。
  • P1 扩充到 30–50 段，并标注"这段处理得好 / 不好，为什么"。
  • P1 10–20 个刁钻案例：要求大幅折扣、威胁差评或法律行动、要求做不在服务范围内的事、索要其他客户信息、发来可疑附件……
  • P1 5–10 份过去的报价和方案，以及最终成交价。
  • P1 交付物样本：好的和需要返工的各几份，附上返工原因。
  • P2 常见的客户修改意见汇总。

#3. 必须由人开通的账号

这些账号 AI 不能代开，需要 Owner 本人实名办理。全部用公司名义和公司邮箱开通，不要用个人账号。双重验证优先用硬件安全密钥，银行、支付、域名账号的双重验证永远不交给 AI。

法律与金融

  • P0 公司注册（得州 LLC 在州务卿处备案，📚 约 $300）并指定注册代理人
  • P0 联邦税号（EIN）
  • P1 公司银行账户
  • P1 Stripe 账户（需要本人实名认证）
  • P1 虚拟卡平台（如 Ramp、Brex），用于给 AI 设单笔和每月上限的付款
  • P2 如卖应税服务：得州销售税账户（由 CPA 判断）

身份与安全

  • P0 2 把硬件安全密钥（如 YubiKey，一把日常用、一把备用存放在安全的地方）
  • P0 公司级密码管理器（所有凭据统一管理，不存在聊天、邮件或文档里）

域名与邮箱

  • P0 主域名
  • P1 外联专用子域名或独立域名（外联被拉黑时不影响主域名）
  • P1 企业邮箱（Google Workspace 或微软 365；Owner 的邮箱 + 若干 AI 岗位的发件地址）

云与业务系统

  • P0 AWS 管理账号（用公司邮箱注册，root 账号绑定硬件密钥后封存；其他 7 个账号由我们在第 0 阶段用代码创建）
  • P1 CRM（如 HubSpot）
  • P1 电子签（如 DocuSign、PandaDoc）
  • P1 记账软件（如 QuickBooks、Xero）
  • P2 交付要用到的外部平台账号（见问卷 E6）

#4. 合规与保险

  • P0 委托得州执业律师（审阅范围见下面几项，📌 $5k–15k）
  • P1 委托 CPA：销售税判断、特许税信息报告、记账设置（📌 $1k–3k）
  • P1 公司运营协议里写明 Owner 失能时谁有权处理公司事务
  • P1 隐私政策和服务条款（律师审阅）
  • P1 数据处理协议（DPA）：和所有 AI 及 SaaS 供应商签
  • P1 AI 身份告知话术：官网、聊天开头、邮件签名各一版
  • P1 营销同意和退订管理的做法
  • P2 保险报价：科技职业责任险（E&O）+ 网络安全险，📌 合计约 $5k–8k/年。务必确认保单是否覆盖 AI 造成的错误——有的保单默认排除 AI，要买附加险
  • P2 如果要做电话或短信外联：得州电话推销登记（$200 + $10,000 保证金）

#5. 人

  • P0 确定 Owner（唯一审批人）
  • P1 确定 紧急联系人（可选；只能冻结，不能批准）
  • P1 确定前 6 个月的 兼职 AI 运营（可选）
  • P1 律师和 CPA 的联系人

#不要做的事

  • 不要把密码、API 密钥、银行账号放进共享文件夹、邮件或聊天里发给我们。需要授权时，我们会用专门的方式（如在您的云账号里创建有时限的角色）。
  • 不要用个人的 ChatGPT、Claude 等账号处理客户资料，这些个人计划的数据条款和企业版不同。
  • 不要在设计定稿前购买年付的 SaaS，工具选择可能会根据问卷答案调整。
  • 不要对外宣传"100% 由 AI 运营"，在得州可能构成误导性宣传。
