推荐架构：AWS Bedrock 路线

一句话：骨架确定，AI 只做判断。每个 AI 人物在 AgentCore 上有独立的身份、会话沙箱和预算，只能通过一扇门（AgentCore Gateway + Policy） 调用工具和查询知识；高风险动作由系统按批准时的载荷原样执行，人物自己碰不到。

#三条最重要的设计约束

  1. 账号就是爆炸半径。 2026 年 10 月披露的 AgentCorruption 攻击链显示：一条提示让带 HTTP 或 shell 工具的 Agent 读到执行角色的凭据，就能调用同账号的其他 Agent、读所有对话、投毒记忆、取走密钥。AWS 的立场是"最小权限由客户负责"。所以：
    • 接触外部内容的人物、掌握业务工具的人物、负责复核的人物，分放在三个不同账号。
    • 控制面（网关、策略、密钥）放进一个不跑任何 AI 人物的账号。
    • 人物不配通用的 shell 或 HTTP 工具，每个人物一个最小权限的执行角色。
  2. "允许做什么"和"决定做什么"分开（NIST 2026 年 Agent 身份原则）。模型只负责"提议"；能不能做，由 Cedar 规则和流程状态机决定。
  3. 唯一的人是最大的单点。 审批分批处理并有防疲劳指标；放宽规则有 24 小时冷静期；Owner 缺席时自动进入安全模式；有一组连 Owner 批准也越不过的硬红线（R4）。

#账号结构

账号 放什么 刻意不放什么
mgmt（管理） Organizations、统一登录、账单、组织级护栏 任何业务工作负载
log-archive（日志） 组织 CloudTrail、审计账本、模型调用日志 任何能删日志的角色
security-tooling（安全） GuardDuty、Security Hub、Config 业务数据
platform（控制面） 网关、策略、密钥、工具、流程骨架、审批、执行器、知识库 任何 AI 人物
agents-edge（边缘人物） 接触原始外部内容的人物 机密数据、高风险工具
agents-core（核心人物） 业务人物 原始外部内容、密钥
agents-assurance（保障人物） 复核官、合规官、哨兵、内审 任何能写业务数据的工具
staging（预发） 影子运行、评估、红队、合成数据 真实客户数据
  • 账号本身不收费；增加的是每个账号的基线服务费，见 成本。
  • 不建议合并：platform 和三个人物账号，它们是防同账号横向接管的主要防线。
  • 可以晚点拆：知识库第一阶段放 platform；客户资料多了再单独拆账号。

#关键决策一览

# 决策 选择 门类型
D1 底座 Bedrock（模型、知识库、护栏）+ AgentCore（运行、网关、策略、身份、记忆、观测、评估、登记） 双向（换底座代价中等）
D2 账号结构 8 个账号 单向（事后拆账号代价高）
D3 业务骨架 Step Functions 标准工作流（状态机 + 回调审批） 双向
D4 人物框架 Strands Agents 跑在 AgentCore Runtime 上 双向
D5 人物协作 工作单 + 事件，人物之间不自由对话 双向
D6 工具接入 所有工具都经网关；人物没有直接外网，也拿不到密钥 单向（原则级）
D7 授权 Cedar 策略，默认拒绝、forbid 优先；阈值只在一个文件里定义 双向
D8 高风险执行 "AI 提议、系统执行"：执行器校验载荷哈希后执行 双向
D9 RAG 托管知识库放在检索服务之后；客户过滤由服务端注入 双向
D10 记忆 按"客户 × 人物"划分；CRM 是客户事实的唯一来源 双向
D11 模型 多模型分档；复核者和制作者用不同的模型家族；锁定版本 双向
D12 护栏 组织级 + 执行角色条件 + 岗位护栏三层强制 双向
D13 审计 自建审计账本，写入不可删除的存储（S3 Object Lock 合规模式） 单向（保留期锁定后不能缩短）
D14 治理框架 NIST AI RMF + 三道防线 + 治理即代码 双向

"单向门"指一旦做了很难回头的决定，需要在前期就和贵司确认；"双向门"以后可以低成本调整。

#模型分档

档位 用在哪里 候选模型（每百万 token 输入/输出）
旗舰档 最难的判断，例如复杂方案 Claude Fable 5.2：$8 / $40（在 Bedrock 上强制 30 天数据保留，只用于不含客户机密的任务）
推理档 幕僚长、合同、复核官 Claude Opus 5.5：$4 / $20
主力档 起草、客服、项目管理 Claude Sonnet 5.5：$2 / $10
经济档 分类、抽取、路由 Claude Haiku 5.5：$0.10 / $0.50；Amazon Nova Micro / Lite
复核档 复核官，必须和制作者用不同的模型家族 Amazon Nova、OpenAI GPT-6.1 Sol（$2 / $10）或 gpt-oss

所有模型锁定版本，用美国境内的推理配置文件（约贵 10%，换来数据不出美国）。

完整设计（含跨账号调用路径、网络、Runtime 外壳代码、记忆隔离等）见 全文 · Bedrock 架构设计。
