术语表

术语 英文 含义
Owner — 公司里唯一的人：所有者、董事会、唯一审批人
AI 人物 Persona 一个受治理的 AI 岗位：岗位卡 + 身份 + 权限 + 预算 + 考核
三道防线 Three lines of defense 业务自控、独立控制、审计
四道闸 — 自检、规则、护栏、独立复核
R0–R4 — 动作风险等级，从只读到禁止
A0–A3 — 自主度等级：影子运行、逐条批准、自动 + 抽查、只处理例外
授权矩阵 Authorization matrix 每类动作在什么额度内由 AI 做、AI 复核、人批准或禁止
单向门 / 双向门 One-way / two-way door 一旦决定很难回头的选择 / 以后可以低成本调整的选择
执行器 Executor 确定性代码，按批准时的载荷执行高风险动作
工作单 Work item AI 人物之间交接工作的结构化记录，替代自由对话
工作单令牌 Work-item token 流程骨架签发的短期签名令牌，写明工作单、客户和人物
载荷哈希 Payload hash 被批准的工具调用参数的指纹，保证"批什么就做什么"
冷静期 Cooling-off period 放宽类变更批准后、生效前的强制等待时间
破窗 Break-glass 紧急情况下的人工越权操作，全程留痕
熔断 Kill switch K1–K5 分级停止
隔离读信员 Quarantine reader 没有任何工具的 AI，把不可信内容转成结构化数据（"双 LLM"模式）
影子运行 Shadow mode AI 做，但结果不发出去，只和人的做法对比
灰度发布 Canary release 新版本先承接一小部分工作，指标达标再全量
质量金丝雀 Quality canary 每小时用生产配置跑几道标准题，及早发现质量下降
蜜罐文档 Honeytoken / canary document 埋在知识库里的独特文档，一旦出现在对外内容里就说明有越权或外泄
提示词注入 Prompt injection 把给 AI 的指令藏在邮件、网页、文档里，诱导 AI 做不该做的事
RAG Retrieval-augmented generation 先从知识库检索资料，再让模型基于资料回答
混合检索 / 重排 Hybrid search / Rerank 关键词 + 语义检索 / 用专门模型对结果重新排序
上下文溯源检查 Contextual grounding check 检查回答是否被检索到的资料支撑
自动推理检查 Automated Reasoning checks 用形式逻辑核对回答是否符合写成规则的政策；只检测，只支持美式英语
MCP Model Context Protocol 给 AI 接工具的开放协议
A2A Agent2Agent AI Agent 之间通信的开放协议
Bedrock Amazon Bedrock AWS 的大模型托管服务，提供多家厂商的模型、知识库和护栏
AgentCore Amazon Bedrock AgentCore AWS 的 Agent 运行与治理服务：运行环境、网关、策略、身份、记忆、观测、评估、登记等
Gateway / Policy AgentCore Gateway / Policy AgentCore 里的"唯一的门"：所有工具调用都经过网关，由策略决定是否放行
Cedar / Dogwood — AgentCore Policy 使用的策略语言；Dogwood 是 Cedar 的超集，增加了时序条件
Guardrails Amazon Bedrock Guardrails Bedrock 的内容安全护栏
Step Functions AWS Step Functions AWS 的托管状态机服务，本方案的流程骨架
SCP / RCP Service / Resource Control Policy AWS 组织级护栏：分别从身份一侧和资源一侧限制
Object Lock 合规模式 S3 Object Lock compliance mode 保留期内任何人（包括 root）都删不掉
AgentCorruption — Zenity 在 2026 年 10 月披露的攻击链：一条提示就能接管同账号同区域的 AgentCore Agent
NIST AI RMF AI Risk Management Framework 美国 NIST 的 AI 风险管理框架
OWASP Agent 十大风险 OWASP Top 10 for Agentic Applications OWASP 在 2025 年 12 月发布的 Agent 应用十大安全风险（ASI01–ASI10）
TRAIGA Texas Responsible AI Governance Act 得州 AI 治理法（HB 149），2026-01-01 生效
DTPA Deceptive Trade Practices Act 得州消费者保护法，针对欺骗性商业行为
TDPSA Texas Data Privacy and Security Act 得州隐私法
CUBI Capture or Use of Biometric Identifier 得州生物识别法
UETA Uniform Electronic Transactions Act 电子交易法（得州第 322 章）
TCPA Telephone Consumer Protection Act 联邦电话消费者保护法
E&O Errors and omissions insurance 职业责任险
DPA Data processing agreement 数据处理协议
